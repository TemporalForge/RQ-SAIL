# NASA data placement

Download the NASA PCoE battery-aging data from the original source and place
the MATLAB files as follows:

```text
data/raw/nasa/B0005.mat
data/raw/nasa/B0006.mat
data/raw/nasa/B0007.mat
data/raw/nasa/B0018.mat
```

B0005 supplies Task-1 train/old-test records, B0006 supplies Task-1 validation,
B0007 supplies the Task-2 chronological split, and B0018 is final test only.
Raw data and generated pickle metadata are not included in this repository.
